# Language Negative Control: "person" Query (2026-07-03)

## Claim under test

A dynamic object that was masked during mapping should be absent from
the language map: querying for it should return nothing beyond noise.

## Design

CLIP relevancy never returns literal zero, so the control is comparative:
query "person" on (a) BONN person_tracking, where a person walked
through every frame but was dynamic-masked, and (b) Replica room0,
where no person ever existed. (b) measures the query pathway's noise
floor with contamination physically impossible. Credit: comparison
design suggested by Ankur.

Both runs: full pipeline, seed 42, current code (through `3d00a86`,
which includes masked language loss + observation seeding + re-seeding).

## Results

| scene | person rel_mean | person rel_max | coverage |
|-------|-----------------|----------------|----------|
| BONN person_tracking (person masked) | 0.220 | 0.989 | 78.6% |
| Replica room0 (no person ever)       | 0.241 | 0.973 | 96.9% |

Reference object queries on BONN: wall 0.464, screen 0.310, monitor
0.128; on Replica: monitor 0.320, wall 0.250, chair 0.121, floor 0.085.

## Verdict

**PASS.** The masked person's residual relevancy (0.220) is at — in
fact slightly below — the person-free noise floor (0.241). The masked
dynamic object leaves no more trace in the language map than an object
that never existed. Earlier hypotheses (surviving contaminated
Gaussians; CLIP context bleed specific to the person) are unnecessary:
the residual is generic query-pathway noise present on any scene.

Paper formulation: report Δ = rel(person | dynamic scene) −
rel(person | person-free scene) ≈ 0 as the negative-control metric.
